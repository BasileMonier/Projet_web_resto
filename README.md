# Projet_web_resto
## -- Bistrot Le Perla'Bul --

Site web d'un bistrot lillois fictif, réalisé dans le cadre d'un projet de formation B1 Décalé Web 2026.
Le site présente la carte du restaurant, une galerie photo, un formulaire de réservation et les informations de contact.

## -- Auteurs --

- Basile — HTML index/contact, CSS complet, lightbox galerie.js, index.js, main.js, déploiement GitHub Pages
- Hiba — HTML menu, HTML galerie, HTML reservation, menu.js, reservation.js, base de données SQL, readme
